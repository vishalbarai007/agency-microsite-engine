Google Sheets Integration via Apps Script

A zero-cost, enterprise-reliable spreadsheet database for client micro-websites. No database billing or cloud infrastructure needed.

Zero Cost Database Google Apps Script Auto-Header Creation Concurrency Safe (LockService)
💡 In Plain English (Why Google Sheets?)

Clients don't want to log in to complicated CMS dashboards or SQL databases to see who contacted them. They want a simple Google Spreadsheet that they already know how to use on their phone and laptop:

  • Every time someone submits a form on the website, a tiny script runs in Google Cloud.
  • It creates clean column headers automatically if the sheet is empty.
  • It appends the new visitor's name, email, phone, service, and message into the next empty row.
  • Multiple people can submit at the exact same second without corrupting the sheet.
  • Cost: $0/month forever.

🚀 7-Minute Setup Walkthrough

1
Create the Google Sheet

Go to sheets.new, name the spreadsheet [Client Name] - Website Leads, and rename the sheet tab at the bottom to Leads.

2
Open Apps Script

In the top menu, click Extensions → Apps Script. Rename the script project to Microsite Ingestion.

3
Paste the Production Script

Replace everything in Code.gs with the code below and hit Ctrl + S (Save).

4
Deploy as a Web App

Click the blue Deploy button → New deployment. Select type Web app. Set Execute as: Me and Who has access: Anyone.

5
Authorize Access

Click Authorize access → choose your account → click Advanced → click Go to Microsite Ingestion (unsafe) → Allow.

6
Copy Webhook URL

Copy the generated Web App URL ending in /exec.

7
Add to .env.local

Paste the URL into your project's .env.local as GOOGLE_SHEETS_WEBHOOK_URL="https://script.google.com/...".

📋 Production Google Apps Script (Code.gs)

This script includes concurrency locking (prevents lost rows if two people submit simultaneously) and automatic header styling:

const SHEET_NAME = "Leads";
const HEADERS = [
  "Timestamp (UTC)",
  "Full Name",
  "Email Address",
  "Phone Number",
  "Service of Interest",
  "Message Content"
];

function doPost(e) {
  const lock = LockService.getScriptLock();
  try {
    lock.waitLock(10000); // Wait up to 10s for concurrent writes
  } catch (err) {
    return createJsonResponse({ status: "error", message: "Lock timeout" }, 429);
  }

  try {
    if (!e || !e.postData || !e.postData.contents) {
      return createJsonResponse({ status: "error", message: "No payload" }, 400);
    }

    const data = JSON.parse(e.postData.contents);
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    let sheet = ss.getSheetByName(SHEET_NAME);
    if (!sheet) { sheet = ss.insertSheet(SHEET_NAME); }

    // Auto-create headers if first row is empty
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(HEADERS);
      const hRange = sheet.getRange(1, 1, 1, HEADERS.length);
      hRange.setFontWeight("bold");
      hRange.setBackground("#1e293b");
      hRange.setFontColor("#f8fafc");
      sheet.setFrozenRows(1);
    }

    // Append data row
    sheet.appendRow([
      data.timestamp || new Date().toISOString(),
      data.fullName || "Unknown",
      data.email || "No Email",
      data.phone || "Not Provided",
      data.service || "General",
      data.message || ""
    ]);

    return createJsonResponse({ status: "success", row: sheet.getLastRow() }, 200);
  } catch (err) {
    return createJsonResponse({ status: "error", message: err.toString() }, 500);
  } finally {
    lock.releaseLock();
  }
}

function createJsonResponse(payload, statusCode) {
  return ContentService.createTextOutput(JSON.stringify(payload))
    .setMimeType(ContentService.MimeType.JSON);
}

⚠️ Troubleshooting Common Issues

Symptom Cause Solution
403 Forbidden / HTML login page returned Deployment "Who has access" was set to "Only myself" Click Deploy → Manage deployments → set Who has access to Anyone
Changes in Code.gs aren't reflected Apps Script requires a new deployment version Click Deploy → Manage deployments → Edit → Select New version → Save
Empty phone numbers breaking rows Missing fallback values The script uses data.phone || "Not Provided" ensuring column alignment is never ruined
