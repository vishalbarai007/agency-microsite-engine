Decoupled Data Layer & Content Contracts

Clean separation of business copy, photos, and links from React UI components for instantaneous zero-bug revisions.

Decoupled Architecture Type-Safe Contracts Zero JSX Touched Fast Revisions
💡 In Plain English (Why Decouple Data?)

In standard websites, text, prices, and photos are tangled up inside complex React code. If a client says "Hey, can you change our tagline from X to Y?", a developer has to hunt through 10 component files, which risks breaking the design:

  • In this engine, all website content lives in simple data files inside src/data/.
  • One file controls the navbar links, one controls the hero text, one controls the services, and one controls the reviews.
  • To change content, anyone (even a junior intern or an AI agent) just changes a single line of text in hero.ts.
  • The website updates automatically across all pages with zero risk of breaking styles.

📂 Content File Organization

src/data/ ├── siteConfig.ts ➔ Brand name, logo, social links, SEO tags & colors ├── navigation.ts ➔ Header navigation tree & footer quick links ├── hero.ts ➔ Main headline, subtitle, buttons, & hero video/photo ├── offerings.ts ➔ Services, packages, features & price tiers ├── testimonials.ts ➔ Client reviews, star ratings, & photo avatars ├── faqs.ts ➔ Frequently asked questions & answers └── units.ts ➔ (Real Estate) Apartment units, sqft, & floor plans

📝 How It Looks in Code

Here is how a service card is defined in src/data/offerings.ts:

export const offeringsData = [
  {
    id: "service-1",
    title: "Bespoke Spatial Design",
    tagline: "Harmonizing light, volume, and material",
    description: "Architectural blueprints and spatial planning for private luxury residences.",
    imageUrl: "https://images.unsplash.com/photo-1600585154340-be6161a56a0c",
    badge: "Signature",
    features: ["Volumetric 3D Modeling", "Bioclimatic Analysis", "Engineering Permits"],
    ctaLink: "#contact"
  }
];

The UI component in src/components/sections/FeatureGrid.tsx just reads this data and loops over it. You never have to edit the component to change a service!
