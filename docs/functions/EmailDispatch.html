💡 In Plain English (Why Resend?)

When a prospect asks for a quote on the website, the agency's client needs to know immediately so they can call them back before they look at a competitor:

  • Within 2 seconds of submission, an alert email lands on the client's smartphone.
  • The email contains the prospect's name, phone, email, chosen service, and exact message formatted in a dark sleek card.
  • Hitting "Reply" in Gmail or Apple Mail replies directly to the prospect's email address, not the system robot.
  • No broken Gmail app passwords or SMTP server timeouts.

⚖️ Resend vs Old-School SMTP (Nodemailer)

Feature Resend API Old Nodemailer / Gmail SMTP
Speed & Latency Sub-250ms HTTPS POST request 3 to 7 seconds TCP handshake (often times out on Vercel)
Stability Enterprise API, 99.99% uptime Breaks when Google rotates 2FA or blocks app passwords
Deliverability Built-in SPF, DKIM, and DMARC verification Frequently flagged as spam or untrusted mail
One-Click Reply Supported via reply_to header Requires complex header overrides

⚙️ Environment Setup

Add these three lines into your .env.local file:

# Resend API Key from https://resend.com/api-keys
RESEND_API_KEY="re_xxxxxxxxxxxxxx"

# Where you want notifications delivered
NOTIFICATION_DESTINATION_EMAIL="sales@agency-client.com"

# Verified sender (Use onboarding@resend.dev during dev/staging)
FROM_EMAIL="Inquiries <onboarding@resend.dev>"
