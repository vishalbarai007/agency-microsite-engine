Agent Skill: build-micro-ecommerce

Automated execution workflow for boutique product drops and direct WhatsApp ordering.

💡 What does invoking this skill do?

When you invoke @build-micro-ecommerce, the AI agent builds a boutique product showcase with a slide-over cart drawer that remembers products and lets buyers order via direct WhatsApp chat or Stripe credit card checkout.

Workflow Phases

  1. Cart Store: Sets up persistent Zustand store in src/lib/store/useCartStore.ts.
  2. Slide-Over Drawer: Adds animated cart drawer with item count badges.
  3. WhatsApp Order Builder: Generates formatted order message links.
  4. Catalog Mapping: Populates products in src/data/offerings.ts.
