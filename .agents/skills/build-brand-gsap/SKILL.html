Agent Skill: build-brand-gsap

Automated execution workflow for luxury, high-motion agency showcases.

💡 What does invoking this skill do?

When you trigger @build-brand-gsap, the AI agent builds a luxury editorial microsite with smooth momentum scrolling (Lenis), parallax photos, and pinned horizontal slide tracks (GSAP ScrollTrigger).

Workflow Phases

  1. Provider Setup: Mounts SmoothScrollProvider in root layout.
  2. Typography Pairing: Applies high-end serif titles and clean geometric body fonts.
  3. Animation Orchestration: Sets up parallax wrappers and pinned horizontal story sequences.
  4. Data Segregation: Fills showcase cards in src/data/offerings.ts.
