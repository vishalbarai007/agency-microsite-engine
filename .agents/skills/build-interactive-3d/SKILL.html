Agent Skill: build-interactive-3d

Automated execution workflow for WebGL 3D canvas and model showcases.

💡 What does invoking this skill do?

When you invoke @build-interactive-3d, the AI agent integrates a Three.js / React Three Fiber 3D hero canvas that smoothly tracks mouse cursor movement and displays interactive rotatable 3D objects with capped resolution for high performance.

Workflow Phases

  1. R3F Canvas Mounting: Configures Three.js canvas with ambient lighting and orbit controls.
  2. Interactive Mesh: Adds mouse-tracking linear interpolation (lerp).
  3. Performance Lock: Caps device pixel ratio to 1.5 to protect mobile devices.
  4. Layout Layering: Overlays glassmorphism headlines and CTA buttons above the 3D canvas.
