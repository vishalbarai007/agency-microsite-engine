Agent Rule: Design Tokens & Aesthetic Presets

Instructions enforced by Antigravity and Claude agents to generate aesthetically distinct websites matching client brand vibes.

💡 What is this file for?

This file is a rulebook for AI coding agents. When you tell the AI "build a website for a luxury hotel", it reads this file so it knows exactly which fonts (Cormorant Garamond), colors (champagne gold and obsidian), and layout spacing to use instead of guessing.

Prescribed Aesthetic Modes

  • premium: Editorial serif typography, champagne gold accents, hairline borders, expansive luxury spacing.
  • funky: Bold neo-brutalist style, electric lime/yellow accents, 3px solid black borders, hard offset drop shadows.
  • minimal: Pure Swiss style, neutral zinc greys, hairline dividers, strict 8pt grid.
  • bold-tech: Midnight slate background, neon cyan/violet glows, glassmorphism cards.
