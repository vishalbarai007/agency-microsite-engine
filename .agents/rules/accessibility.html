Agent Rule: Accessibility & Responsiveness

Universal quality guidelines ensuring every AI-generated site is fast, accessible, and mobile-friendly.

💡 What is this file for?

This rule guarantees that websites built by AI agents don't break on small smartphone screens and remain easily readable with high contrast for people with visual impairments.

Enforced Standards

  • WCAG 2.1 AA Contrast: Text colors are always readable with sharp contrast against dark backgrounds.
  • 44px Touch Targets: All buttons and inputs are comfortable to tap on mobile touchscreens.
  • Semantic HTML: Strictly uses proper HTML tags (<header>, <main>, <footer>) for SEO and screen readers.
  • Descriptive Image Alt Text: Every photo has meaningful description attributes for search engines and accessibility tools.
