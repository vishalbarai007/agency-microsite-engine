Agent Rule: Data Contracts & Isolation

Architectural constraints that force the AI agent to isolate all website content into dedicated data files.

💡 What is this file for?

This rule forces the AI agent to never write text or prices directly into page code. It forces the agent to create clean content files in src/data/, making future edits 10x faster and completely eliminating code regressions.

Enforced Standards

  • Strict Data Separation: All text and image URLs live exclusively in src/data/*.ts.
  • TypeScript Typing: Every data file must conform to src/types/dataContracts.ts.
  • Reliable Fallbacks: Contextual high-res Unsplash CDN links are used whenever custom media is unavailable.
