# Agent Rule: Accessibility & Responsiveness Standards

## Objective
Every microsite generated by the agent must pass basic WCAG 2.1 AA accessibility checks and render flawlessly across all mobile and desktop viewports.

---

## Strict Rules

1. **Semantic HTML Elements**:
   - Use `<main>`, `<header>`, `<footer>`, `<section>`, `<nav>`, and `<article>`.
   - Never nest `<button>` inside `<a>` or vice versa.
   - Maintain heading hierarchy: one single `<h1>` per page, followed by `<h2>` for sections, and `<h3>` for cards.

2. **Contrast & Legibility**:
   - Primary text against dark backgrounds must meet at least 4.5:1 contrast ratio (e.g. `#F8FAFC` on `#090D16`).
   - Muted secondary text must be at least `#94A3B8` (slate-400) or higher.

3. **Mobile Navigation & Touch Targets**:
   - Touch targets (buttons, links, inputs) must be at least 44px by 44px on mobile devices.
   - Mobile navigation hamburger menu must manage focus traps, escape key closing, and `aria-expanded` state.

4. **Media Alt Text**:
   - Every `next/image` component must contain a descriptive, contextual `alt` attribute. Never leave `alt=""` or `alt="image"`.
