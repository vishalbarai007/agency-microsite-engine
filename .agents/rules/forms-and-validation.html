Agent Rule: Forms & Validation Standards

Security and validation mandates that AI agents must enforce when building forms.

💡 What is this file for?

This rule ensures the AI agent never writes unsafe or unvalidated forms. It mandates Zod validation, invisible bot traps, and automatic dispatch to Google Sheets and client inboxes.

Enforced Standards

  • Zod Type Safety: Validates text length and email structure on both browser and server.
  • Honeypot Trap: Blocks spam bots automatically without annoying CAPTCHAs.
  • Server Action Privacy: Never exposes secret webhook URLs or API keys in the client browser.
  • Sonner Feedback: Shows instant modern toast confirmations upon submission.
